## To run the experiments

1. Navigate to the `bf` directory:

   ```bash
   cd bf
   ```

2. Run the AOL experiment:

   ```bash
   python aol_experiment.py
   ```

3. Run the CIC-IDS experiment:

   ```bash
   python cic-ids.py
   ```

## Notes

- Ensure all necessary datasets are available in the right paths before running the experiments.
